# Month snapshot report (report 8)

Owner one-pager for a calendar month (Asia/Dhaka): net sales, COGS, gross profit, cash collected, live AR, wallet liability, unsold stock value.

**RPC:** `get_tenant_month_snapshot_report(p_tenant_id, p_month date)`  
**Route:** `/:tenantSlug?/app/finance/reports/month-snapshot`

Tiles link to the underlying detail reports with the same month range where applicable.
