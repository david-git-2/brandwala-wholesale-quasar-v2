# `product_based_costing` Module

- **Purpose:** Shop-order product-based costing files (`parentModuleKey: 'shop_order'`), accessible to Admin and Staff.
- **Routes:** `/app/product-based-costing`.
- **Tables:** `product_based_costing_files`, `product_based_costing_items` (linked to `products`).
- **Note:** This is a separate feature from [`../../../preorder_costing_file/`](../../../preorder_costing_file/README.md) (which handles pre-order costing files), not a V2 replacement of it.
