# Operating manual

Step-by-step procedures for staff who run TradeFlow day to day: receive stock, sell, bill, collect cash, and configure shops.

This manual is **not** the platform architecture guide. For kernels, modules, and how the system fits together, see the [Platform guide](/docs).

## Who this is for

| Audience | Use this manual for |
| :--- | :--- |
| App staff (tenant ERP) | Warehouse, sales desk, payments, shop setup |
| Shop users | Orders and account basics (short sections as we add them) |

Login surfaces (`app`, `shop`, `platform`, `investor`) are explained under [Scopes](/docs/scopes) in the platform guide.

## How to read it

1. Start on the page that matches your job (sections will grow over time).
2. Follow steps in order unless a note says otherwise.
3. When a step mentions a rule you do not understand, open the linked platform doc — do not guess.
