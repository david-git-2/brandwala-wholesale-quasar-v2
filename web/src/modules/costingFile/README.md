# `costingFile` Module (`costing_file` / "Pre order")

- **Purpose:** Pre-order costing files and price preparation across Admin, Staff, Viewer, and Customer roles.
- **Routes:** `/app/costing` (and `/shop/...` customer routes).
- **Tables:** `costing_files`, `costing_file_items`.
- **Note:** This is a separate feature from [`../product_based_costing/`](../product_based_costing/README.md) (which handles shop-order product-based costing), not a legacy V1 of it.
